# Exigences Fonctionnelles et Non-Fonctionnelles

| Fonctionnelles                                                           | Non-Fonctionnelles                                    |
| ------------------------------------------------------------------------ | ----------------------------------------------------- |
| Système d'inscription des mentors et mentorés via Discord                | Le système doit fonctionner sur Discord               |
| Gestion des profils (mentor/mentoré) avec informations requises          | Protection des données personnelles                   |
| Système de matching automatique basé sur expertise/langue/disponibilités | Temps de réponse rapide pour les matchings            |
| Planification et gestion des sessions de mentorat                        | Haute disponibilité du système                        |
| Système de feedback post-session                                         | Interface utilisateur intuitive via commandes Discord |
| Système de notifications (rappels, annulations)                          | Système de backup des données                         |
| Filtrage et recherche de mentors                                         | Performance avec montée en charge                     |
| Gestion des disponibilités des mentors                                   | Sécurité des communications                           |
| Système anti-spam pour les demandes de mentorat                          | Respect de la RGPD                                    |
| Historique des sessions et feedbacks                                     | Maintainabilité du code                               |
| Tableau de bord pour les administrateurs                                 | Scalabilité du système                                |
| Système de badges et reconnaissance                                      |                                                       |
