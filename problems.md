| **Problématiques**                                  | **Problèmes identifiés**                            | **Solutions proposées**                                                          |
| --------------------------------------------------- | --------------------------------------------------- | -------------------------------------------------------------------------------- |
| Comment intégrer des gens au système de mentorat ?  | Peu de visibilité sur le programme                  | Création d’un salon `#🚀-devenir-mentor` avec infos claires + call-to-action     |
|                                                     | Inscription peu engageante                          | Formulaire simple intégré à Discord (type `/inscription` ou bouton réaction)     |
|                                                     | Aucun onboarding spécifique                         | Message privé automatisé avec explication du rôle et des étapes                  |
| Comment garder les gens liés au système ?           | Perte d’intérêt après quelques semaines             | Relances automatiques après 15j d’inactivité (statut “disponible” / “non dispo”) |
|                                                     | Aucune reconnaissance visible                       | Badges, rôles dynamiques visibles publiquement (Mentor actif, Mentor top, etc.)  |
|                                                     | Manque d’animation                                  | Workshops ouverts aux anciens + salons vocaux spontanés                 |
| Comment mettre en correspondance mentors/mentorés ? | Matching lent ou manuel                             | Système de matching semi-automatique basé sur domaines / créneaux / langue       |
|                                                     | Spams de demandes à un seul mentor                  | Limitation à 3 demandes par semaine, cooldown après un refus                     |
|                                                     | Certains mentors sont sur-sollicités                | Option “Indisponible” qui masque temporairement le mentor                        |
| Comment gérer la logistique des sessions ?          | Sessions oubliées ou mal organisées                 | Création automatique d’un salon dédié + rappel 24h avant                         |
|                                                     | Aucune trace des échanges                           | Archivage automatique dans un salon privé ou fichier markdown                    |
|                                                     | Problèmes de fuseaux horaires ou retards            | Clarification des horaires en timezone fixe, message auto en cas de non-venue      |
| Comment évaluer l’efficacité du programme ?         | Pas de retours utilisateurs                         | Formulaire de feedback court après chaque session (note + commentaire)           |
|                                                     | Aucun indicateur de qualité                         | Stats visibles (nombre de sessions, moyenne de satisfaction)                     |
|                                                     | Difficulté à repérer les mentors les plus efficaces | Système de score interne basé sur feedbacks et activité                          |
| Comment garantir un cadre sécurisé et respectueux ? | Aucun signalement possible                          | Bouton de signalement sur chaque session ou profil                               |
|                                                     | Comportements inappropriés non modérés              | Rappel des règles, sanction rapide si non-respect, charte obligatoire            |
|                                                     | Risque de harcèlement ou spam                       | Anti-spam intégré + modération humaine active sur les messages privés            |
